<task type="auto">
  <name>Task 1: Gemini fallback proxy + command bar NL integration</name>
  <files>api/gemini-query.js, shared/interactions.js</files>
  <action>
1. Create `api/gemini-query.js` — Vercel Serverless Function:
   - POST endpoint accepting `{ userQuery, roleContext, metricas }`
   - `roleContext` is the user's role string (ceo/vp/sdr)
   - `metricas` is AGGREGATED data only (counts, percentages, dates) — NEVER PII (no email, telefono, nombre, RUT)
   - Build prompt for Gemini 2.5 Flash:
     ```
     Eres un asistente de ventas B2B chileno para el rol de ${roleContext}.
     Metricas del pipeline: ${JSON.stringify(metricas)}
     Pregunta del usuario: "${userQuery}"
     Responde en JSON con este formato exacto:
     { "titulo": "string (titulo corto de la respuesta)",
       "valor": "string (dato duro principal)",
       "unidad": "string (%, leads, CLP, etc)",
       "narrativa": "string (1-2 oraciones interpretativas)" }
     ```
   - Call Gemini API: `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=${process.env.GEMINI_API_KEY}`
   - Use `generationConfig: { responseMimeType: "application/json" }` for structured JSON response
   - Parse response: `data.candidates[0].content.parts[0].text` → JSON.parse
   - Error handling: if Gemini fails, return `{ error: "No pude procesar tu consulta. Intenta reformular." }`
   - Rate limit: basic check (max 20 calls/hour per org — store in simple memory map, acceptable for MVP)

2. Update `shared/interactions.js` — command bar fallback flow:
   - When user types a query in the command bar and presses Enter:
     a. First: try to match against predefined query buttons (existing logic)
     b. If no match: show loading state ("Pensando...") and call Gemini fallback
     c. Call: `fetch('/api/gemini-query', { method: 'POST', body: JSON.stringify({userQuery, roleContext, metricas}) })`
     d. Before calling: fetch current aggregated stats via `queryConvex(api.stats.getLeadsStats)` to populate `metricas`. CRITICAL: only send aggregate counts, never individual lead data.
     e. On response: render Gemini's answer as mini-card (titulo + valor grande + unidad) with narrativa text below. Use GSAP animateBlockIn.
     f. On error: show friendly message per CONTEXT ("No encontre esa informacion. Prueba con otra pregunta.")
   - Per CONTEXT: "Sin match: intenta Gemini como fallback antes de mostrar error"

3. Implement command bar history:
   - Store last 5 queries in localStorage key `sisteco_query_history`
   - Each entry: `{ query: string, timestamp: number, type: "predefined"|"gemini" }`
   - When command bar is clicked/focused: show history dropdown above the input
   - Clicking a history item re-executes that query
   - Per CONTEXT: "ultimas 5 consultas del usuario, visibles al abrir el command bar"

4. Implement command bar persistencia:
   - Save current active query to localStorage key `sisteco_last_query`
   - On page load: restore last query (re-execute it)
   - Per CONTEXT: "al recargar pagina, restaura la ultima vista/query que tenia abierta"

5. Implement "Copiar resumen" as a command bar query:
   - When user types "copiar resumen" or clicks predefined button: copy the current content area text to clipboard
   - Show toast "Resumen copiado al portapapeles"
