**0. Add public `acceptDpa` mutation to convex/subscriptions.ts:**

Add a new exported mutation (NOT internalMutation) that the dashboard can call:

```typescript
export const acceptDpa = mutation({
  args: { dpaVersion: v.string() },
  handler: async (ctx, args) => {
    const identity = await ctx.auth.getUserIdentity();
    if (!identity) throw new Error("Not authenticated");
    const orgId = identity.org_id as string;
    if (!orgId) throw new Error("No organization");

    const sub = await ctx.db
      .query("subscriptions")
      .withIndex("by_orgId", q => q.eq("orgId", orgId))
      .first();
    if (!sub) throw new Error("No subscription found");

    await ctx.db.patch(sub._id, {
      dpaSignedAt: Date.now(),
      dpaVersion: args.dpaVersion,
      updatedAt: Date.now(),
    });
    return { ok: true };
  },
});
```

Remember to import `mutation` at the top of subscriptions.ts (alongside `query`, `internalMutation`, `internalQuery`).

**1. Create app/shared/trial-banner.js:**

This is a vanilla JS module (same pattern as existing app/shared/*.js files). It:
- Exposes `window.SistecoTrialBanner = { init }` as a global
- `init()` function:
  1. Gets the current user's org subscription via `window.SistecoConvex.queryConvex("subscriptions:getByOrgId", { orgId })` — the orgId comes from the Clerk user identity
  2. If no subscription found, return silently (user might not have a trial yet)
  3. Calculate `daysRemaining = Math.ceil((sub.trialEndsAt - Date.now()) / (24*60*60*1000))`
  4. Create and insert a banner div at the TOP of `document.body` (before first child)

Banner states:

**Trial active (status === "trial", daysRemaining > 0):**
- Background: #f0ffd9 (light green)
- Border-bottom: 2px solid #c5ed36
- Text: `"Trial gratuito — Quedan ${daysRemaining} dias"`
- CTA button: "Contratar ahora" → triggers DPA acceptance modal (see dpa-acceptance.js)
- Style: horizontal flex, space-between, padding 12px 24px, font-size 14px

**Grace period (status === "grace"):**
- Background: #fff3e0 (light orange)
- Border-bottom: 2px solid #ff9800
- Text: "Tu pago fallo — Pipeline pausado en 7 dias"
- CTA button: "Actualizar pago" → opens Reveniu link for their plan

**Trial expired (status === "expired"):**
- Background: #fff0f0 (light red)
- Border-bottom: 2px solid #f44336
- Text: "Tu trial vencio"
- CTA button: "Ver planes" → opens Reveniu link for base plan
- Additional: overlay the dashboard content with 50% opacity to signal it's locked

**Active (status === "active"):**
- No banner shown (user is paying)

**Paused (status === "paused"):**
- Background: #f5f5f5
- Text: "Tu cuenta esta pausada — contacta a contacto@sisteco.cl"
