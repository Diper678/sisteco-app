**File 1: convex/retention.ts**

Create with `internalMutation` from "./_generated/server" and `v` from "convex/values".

Define constants at top of file:
```typescript
const RETENTION_MS = 24 * 30 * 24 * 60 * 60 * 1000;      // ~24 months
const MAX_RETENTION_MS = 36 * 30 * 24 * 60 * 60 * 1000;   // ~36 months
const GRACE_PERIOD_MS = 30 * 24 * 60 * 60 * 1000;          // 30 days
const BATCH_SIZE = 100;
```

**1. scanExpiredLeads** — internalMutation, no args:
Steps:
1. `const now = Date.now()`
2. Query leads table filtering for:
   - complianceStatus is NOT "opt_out", NOT "eliminado", NOT "anonimizado" (or complianceStatus is undefined — active leads)
   - fechaExpiracion exists and is < now
3. Use `.filter()` since we cannot combine multiple field conditions with a single index. Query all leads, filter in handler.
4. Take BATCH_SIZE results.
5. For each expired lead:
   - Set complianceStatus to "expirado"
   - Set softDeletedAt to now
   - Set hardDeleteScheduledAt to now + GRACE_PERIOD_MS
   - Anonymize PII: contacto -> "[EXPIRADO]", email -> `expired-${lead._id}@retention.local`, telefono -> undefined, linkedinUrl -> undefined
   - Set lastUpdatedAt to now
   - Append audit trail: accion "Retencion expirada — datos anonimizados automaticamente", usuarioId "system", usuarioNombre "Retention Cron"
6. Log: `console.log(\`Retention scan: ${processed} leads processed\`)`

**2. hardDeleteExpired** — internalMutation, no args:
Steps:
1. `const now = Date.now()`
2. Query leads table, filter for:
   - complianceStatus is "opt_out" OR "expirado" OR "anonimizado"
   - hardDeleteScheduledAt exists and is < now
3. Take BATCH_SIZE results.
4. For each lead: `await ctx.db.delete(lead._id)`
5. Log: `console.log(\`Hard delete batch: ${deleted} leads permanently deleted\`)`

**3. updateInteraction** — internalMutation:
Args: leadId (v.id("leads"))
Steps:
1. Get lead by ID. If not found, return.
2. If complianceStatus is "opt_out" or "eliminado" or "anonimizado", return (don't extend dead leads).
3. Calculate new expiration:
   - `const newExpiry = Date.now() + RETENTION_MS`
   - `const maxExpiry = (lead.discoveredAt || Date.now()) + MAX_RETENTION_MS`
   - `const finalExpiry = Math.min(newExpiry, maxExpiry)`
4. Patch lead: ultimaInteraccion -> Date.now(), fechaExpiracion -> finalExpiry, lastUpdatedAt -> Date.now()
5. Return { success: true, nuevaExpiracion: finalExpiry }
