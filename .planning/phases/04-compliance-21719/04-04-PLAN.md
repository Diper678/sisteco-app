**Part B: Create convex/sheetsPropagation.ts**

Import `v` from "convex/values", `internalAction, internalQuery` from "./_generated/server", and `internal` from "./_generated/api".

**1. propagateOptOutToSheets** — internalAction:
Args: email (string), tenantsAfectados (array of strings — orgIds).
Steps:
1. For each orgId in tenantsAfectados:
   a. Query tenantSheets table (via ctx.runQuery) by orgId to get spreadsheetId
   b. If no spreadsheetId found for this tenant, log and skip
   c. Call Google Sheets API to find the row with matching email:
      - Use `fetch` to call Sheets API: `https://sheets.googleapis.com/v4/spreadsheets/${spreadsheetId}/values/${sheetName}?key=${process.env.GOOGLE_SHEETS_API_KEY}`
      - Parse response to find row index where email column matches
   d. If row found, delete it using Sheets batchUpdate API:
      - `fetch(\`https://sheets.googleapis.com/v4/spreadsheets/${spreadsheetId}:batchUpdate\`, { method: "POST", ... })` with deleteRange request
   e. Log result: `console.log(\`Sheet propagation: deleted row for ${email} from tenant ${orgId} sheet ${spreadsheetId}\`)`
2. Return { processed: tenantsAfectados.length, deleted: successCount }

NOTE: If Google Sheets API key is not available (process.env.GOOGLE_SHEETS_API_KEY is undefined), log a warning and skip Sheet propagation gracefully. The opt-out in Convex already succeeded — Sheet propagation is best-effort for MVP.

**2. notifyTenantsOfDeletion** — internalAction:
Args: email (string), tenantsAfectados (array of strings — orgIds), reason (string — "opt_out" or "retencion_expirada").
Steps:
1. Build notification message:
   - If reason is "opt_out": "Un lead ha solicitado eliminacion de datos (opt-out). Email: [REDACTED]. Por favor elimine este contacto de su CRM. Referencia: Ley 21.719."
   - If reason is "retencion_expirada": "Un lead ha expirado por retencion (24 meses sin interaccion). Email: [REDACTED]. Por favor elimine este contacto de su CRM."
   - Do NOT include the actual email in Discord/email notification for privacy. Use first 3 chars + "***" pattern.
2. Send Discord notification via webhook (if DISCORD_WEBHOOK_URL exists):
   - `fetch(process.env.DISCORD_WEBHOOK_URL, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ content: \`[COMPLIANCE] ${message}\nTenants afectados: ${tenantsAfectados.length}\nAccion requerida: eliminar de CRM\` }) })`
3. Optionally send email notification via Resend (if RESEND_API_KEY exists):
   - For each tenant, if we had their admin email, send notification. For MVP, Discord is the primary channel.
4. Return { notified: true }

**3. getTenantSheets** — internalQuery:
Args: orgId (string).
Returns the tenantSheets entry for this org, or null.

**4. triggerArcoPolWebhook** — internalAction:

**Part A: Wire Sheet propagation into executeGlobalOptOut (convex/optOut.ts)**

Modify `executeGlobalOptOut` in convex/optOut.ts to schedule Sheets propagation and tenant notification AFTER the Convex opt-out succeeds. Since `executeGlobalOptOut` is an internalMutation (not an action), it cannot call actions directly. Instead, use `ctx.scheduler.runAfter(0, ...)` to schedule the propagation action to run immediately after the mutation completes:

Add at the END of executeGlobalOptOut, after the anonymization loop:
```typescript
// Schedule Sheets propagation + tenant notification (async, non-blocking)
await ctx.scheduler.runAfter(0, internal.sheetsPropagation.propagateOptOutToSheets, {
  email: originalEmail,  // save the original email BEFORE anonymization
  tenantsAfectados: uniqueOrgIds,
});
await ctx.scheduler.runAfter(0, internal.sheetsPropagation.notifyTenantsOfDeletion, {
  email: originalEmail,
  tenantsAfectados: uniqueOrgIds,
  reason: "opt_out",
});
```

IMPORTANT: The original email must be captured BEFORE the anonymization loop replaces it. Add `const originalEmail = email;` at the top of the handler if not already present. The `uniqueOrgIds` should be the deduplicated list of orgIds from affected leads (already computed in the current implementation as tenantsAfectados).
