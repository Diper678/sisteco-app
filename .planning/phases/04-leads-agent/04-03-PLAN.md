**Nodo 6 — Build Scoring Prompt:**
Code node (JavaScript) que construye el prompt para Gemini:

```javascript
const lead = $json.lead;
const insights = $json.previousInsights || '';
const enriched = lead.enrichedData || {};

const prompt = `Eres un experto en ventas B2B en Chile para Sisteco, una plataforma SaaS de automatizacion de ventas.

PERFIL DE CLIENTE IDEAL (ICP) DE SISTECO:
- Empresas B2B chilenas con 50+ empleados
- Industrias: SaaS, Fintech, Servicios profesionales, Manufactura, Logistica
- Con equipo de ventas activo (3+ vendedores)
- Que usen o necesiten CRM (HubSpot, Salesforce, o ninguno)
- Decision makers: VP Ventas, Director Comercial, Gerente de Ventas, CEO

LEAD A EVALUAR:
- Empresa: ${lead.empresa || 'Desconocida'}
- Industria: ${lead.industria || 'No detectada'}
- Tamano: ${lead.tamano || 'No detectado'}
- Ubicacion: ${lead.ubicacion || 'Chile'}
- Website: ${lead.websiteUrl || 'N/A'}
- Contacto: ${lead.contacto || 'No disponible'}
- Email: ${lead.email || 'No disponible'}
- Descripcion del sitio: ${enriched.descripcion || 'No disponible'}
- Productos/Servicios: ${JSON.stringify(enriched.productos || [])}
- Stack detectado: ${JSON.stringify(enriched.stack_detectado || [])}
- Contenido preview: ${(enriched.contenido_preview || '').substring(0, 500)}

${insights ? 'INSIGHTS DE SCORING PREVIOS (aprende de estos):\\n' + insights : ''}

INSTRUCCIONES:
Evalua este lead de 0-100 puntos segun su fit con el ICP de Sisteco.
Criterios:
- +30 max: Industria y modelo B2B alineado
- +25 max: Tamano de empresa adecuado (50+ empleados)
- +20 max: Senales de necesidad de automatizacion de ventas
- +15 max: Datos de contacto disponibles (email, telefono)
- +10 max: Stack tecnologico compatible o ausencia de CRM (oportunidad)

Responde SOLO en JSON con este formato exacto:
{
  "score": <numero 0-100>,
  "category": "<HOT|WARM|NURTURE|SKIP>",
  "reasoning": "<explicacion en 2-3 oraciones en espanol>",
  "signals": ["<senal_positiva_1>", "<senal_positiva_2>"],
  "risks": ["<riesgo_1>"]
}

Categorias: HOT (80-100), WARM (50-79), NURTURE (20-49), SKIP (0-19)`;

return { json: { prompt, leadId: lead._id, leadEmpresa: lead.empresa } };
```

**Nodo 7 — Call Gemini API:**

```json
    "temperature": 0.3,
    "maxOutputTokens": 500
  }

```

**Nodo 8 — Wait Rate Limit:** Wait 7 segundos (10 RPM = 1 cada 6s, con margen).

**Nodo 9 — Parse Gemini Response:**
Code node:
```javascript
const response = $json;
const text = response.candidates?.[0]?.content?.parts?.[0]?.text || '{}';
let scoring;
try {
  scoring = JSON.parse(text);
} catch (e) {
  scoring = { score: 0, category: "SKIP", reasoning: "Error parsing Gemini response", signals: [], risks: ["parse_error"] };
}

// Validar categoria
const validCategories = ["HOT", "WARM", "NURTURE", "SKIP"];
if (!validCategories.includes(scoring.category)) {
  if (scoring.score >= 80) scoring.category = "HOT";
  else if (scoring.score >= 50) scoring.category = "WARM";
  else if (scoring.score >= 20) scoring.category = "NURTURE";
  else scoring.category = "SKIP";
}

return { json: { ...scoring, leadId: $json.leadId, leadEmpresa: $json.leadEmpresa } };
```

**Nodo 11 — Check if HOT:**
