  <files>SAAN/convex/leads.ts</files>
  <behavior>
    - upsertLead: Si ya existe un lead con el mismo email O la misma empresa, actualiza en vez de crear duplicado
    - upsertLead: Retorna el _id del lead (nuevo o existente actualizado)
    - getLeadByEmail: Retorna null si no existe
    - getLeadByCompany: Retorna null si no existe
    - getLeadsByStatus: Retorna array de leads filtrados por status
    - getLeadsByScore: Retorna leads con score >= minScore, ordenados desc
    - updateLeadStatus: Actualiza status y lastUpdatedAt
    - updateLeadScore: Actualiza score, scoreCategory, scoreReasoning y lastUpdatedAt
    - getLeadsStats: Retorna conteo por scoreCategory (HOT, WARM, NURTURE, SKIP)
  </behavior>
  <action>
Crear `SAAN/convex/leads.ts` con las siguientes funciones:

1. **upsertLead** (mutation): Recibe datos del lead. Busca primero por email (si tiene), luego por empresa. Si encuentra, hace patch con datos nuevos (merge). Si no, inserta. Siempre actualiza `lastUpdatedAt = Date.now()`. Para leads nuevos, `discoveredAt = Date.now()`, `status = "new"`, `score = 0`, `scoreCategory = "SKIP"`.

2. **getLeadByEmail** (query): Busca por indice `by_email`. Retorna el primero o null.

3. **getLeadByCompany** (query): Busca por indice `by_empresa`. Retorna el primero o null.

4. **getLeadsByStatus** (query): Filtra por status usando indice `by_status`. Acepta limit opcional (default 50).

5. **getLeadsByScore** (query): Acepta `minScore` (number). Usa indice `by_score`. Filtra score >= minScore. Ordena desc. Limit opcional (default 50).

6. **updateLeadStatus** (mutation): Recibe leadId (v.id("leads")) y status. Patch con nuevo status y lastUpdatedAt.

7. **updateLeadScore** (mutation): Recibe leadId, score, scoreCategory, scoreReasoning. Patch todos + lastUpdatedAt. Si scoreCategory cambia a "scored" en status, tambien actualiza status.

8. **getLeadsStats** (query): Sin args. Consulta todos los leads, agrupa por scoreCategory y retorna conteos: `{ hot: N, warm: N, nurture: N, skip: N, total: N }`.

9. **batchUpsertLeads** (mutation): Recibe array de leads. Para cada uno llama la logica de upsertLead. Retorna `{ inserted: N, updated: N, total: N }`. Maximo 50 leads por batch para no exceder limites de Convex.

Importar de "convex/values" y "./_generated/server". Usar indices para todas las queries.
