export const upsertAgentState = mutation({
  args: { agentId: v.string(), status: v.string(), ... },
  handler: async (ctx, args) => {
    const existing = await ctx.db.query("agentsState")
      .withIndex("by_agent_id", (q) => q.eq("agentId", args.agentId))
      .unique();

    return await ctx.db.insert("agentsState", {...});
  },
});

Crear SAAN/convex/finance.ts siguiendo el patron de agents.ts (import mutation/query, v validators, handlers async).

**Funciones requeridas:**

1. **upsertSubscription** (mutation): Recibe todos los campos de subscriptions. Busca por customerId con index. Si existe, patch. Si no, insert. Retorna _id.

2. **getActiveSubscriptions** (query): Usa index by_status con eq("active"). Retorna array.

3. **getSubscriptionByCustomerId** (query): Busca por index by_customer_id. Retorna unica o null.

4. **recordFailedPayment** (mutation): Recibe customerId. Busca la suscripcion, incrementa failedPaymentCount, setea lastPaymentStatus="failed". Si failedPaymentCount >= 3, cambia status a "past_due". Retorna objeto con { subscriptionId, failedCount, isPastDue }.

5. **recordSuccessfulPayment** (mutation): Recibe customerId. Resetea failedPaymentCount a 0, setea lastPaymentStatus="success", lastPaymentAt=Date.now().

6. **cancelSubscription** (mutation): Recibe customerId. Setea status="cancelled", cancelledAt=Date.now().

7. **saveFinancialMetrics** (mutation): Recibe todos los campos de financialMetrics. Upsert por date (busca con index by_date). Retorna _id.

8. **getLatestMetrics** (query): Recibe limit (default 30). Ordena por date desc. Retorna array.

9. **calculateDailyMetrics** (query): Calcula en tiempo real desde tabla subscriptions:
   - MRR = suma de amountUsd de suscripciones activas (si billingCycle="annual", dividir entre 12)
   - activeSubscriptions = count de status="active"
   - ARPU = MRR / activeSubscriptions (o 0 si no hay)
   - churnRate: consultar financialMetrics del mes anterior para calcular. Si no hay datos previos, usar 0.05 (5% default industria SaaS Chile)
   - LTV = ARPU / churnRate (si churnRate > 0, sino ARPU * 20 como cap)
   - revenueByPlan: agrupar MRR por plan { inicio, crecimiento, enterprise }
   - Retorna objeto con todos estos campos

10. **saveMetricsToMemory** (mutation): Recibe metricas calculadas. Llama internamente a ctx.db.insert en agentMemory con agentId="finance", memoryType="report", content=JSON.stringify del snapshot, tags=["metrics", "daily", fecha]. NO importar saveMemory de agents.ts — insertar directamente en la tabla (mismo patron que agents.ts usa).
