**Parte A: Endpoint HTTP en Convex (SAAN/convex/http.ts)**

Si http.ts ya existe (creado en Phase 2), agregar una nueva ruta. Si no existe aun, crear el archivo base con httpRouter.

Agregar ruta POST `/webhooks/reveniu` que:
1. Lee el body del request como JSON
2. Valida el header `X-Reveniu-Secret` contra la variable de entorno REVENIU_WEBHOOK_SECRET (si no tiene variable de entorno disponible en Convex, al menos validar que el header existe)
3. Extrae el tipo de evento del body (Reveniu envia eventos como: `payment.success`, `payment.failed`, `subscription.created`, `subscription.cancelled`)
4. Segun el tipo de evento, llama a la mutation correspondiente de finance.ts:
   - `payment.success` -> recordSuccessfulPayment(customerId)
   - `payment.failed` -> recordFailedPayment(customerId) + enviar alerta (via agentMessages al monitor para relay a Telegram)
   - `subscription.created` -> upsertSubscription(datos del evento)
   - `subscription.cancelled` -> cancelSubscription(customerId)
5. Retorna 200 OK con { received: true }
6. En caso de error, retorna 500 con { error: message }

NOTA: El formato exacto del payload de Reveniu puede variar. Usar un mapper flexible que extraiga customerId, amount, plan del body. Documentar el formato esperado con un comentario.

NOTA 2: Para la alerta de cobro fallido (FIN-05), cuando llega `payment.failed`:
- Llamar a recordFailedPayment para actualizar la suscripcion
- Insertar un agentMessage de fromAgent="finance" toAgent="monitor" con messageType="alert" priority="critical" y payload con los datos del cobro fallido (customerName, amount, failedCount)
- El Monitor Agent (Phase 3) se encargara de enviar a Telegram. Si Phase 3 no esta lista, crear un workflow n8n dedicado (ver Parte B).

**Workflow A: saan-finance-metrics-daily.json (cron diario 23:00 Chile)**

2. **Set Agent Active** (HTTP Request): POST a Convex
   - URL: `{{ $env.CONVEX_SITE_URL }}/mutation/agents/upsertAgentState`
   - Body: { "args": { "agentId": "finance", "status": "active", "currentTask": "daily_metrics_calculation" } }

3. **Get Active Subscriptions** (HTTP Request): POST a Convex
   - URL: `{{ $env.CONVEX_SITE_URL }}/query/finance/getActiveSubscriptions`
   - Body: { "args": {} }

4. **Calculate Metrics** (Code node, JavaScript): Recibe las suscripciones y calcula:
   ```javascript
   const subs = $input.first().json;
   const today = new Date().toISOString().split('T')[0];

   let mrr = 0;
   const byPlan = { inicio: 0, crecimiento: 0, enterprise: 0 };
   let active = 0;

   for (const sub of subs) {
     if (sub.status === 'active') {
       const monthly = sub.billingCycle === 'annual' ? sub.amountUsd / 12 : sub.amountUsd;
       mrr += monthly;
       byPlan[sub.plan] = (byPlan[sub.plan] || 0) + monthly;
       active++;
     }
   }

   const arpu = active > 0 ? mrr / active : 0;
   const churnRate = 0.05; // Default 5%, se ajusta con datos historicos
   const ltv = churnRate > 0 ? arpu / churnRate : arpu * 20;

   return [{
     json: {
       date: today,
       mrr: Math.round(mrr * 100) / 100,
       activeSubscriptions: active,
       churnRate,
       ltv: Math.round(ltv * 100) / 100,
       arpu: Math.round(arpu * 100) / 100,
       failedPayments: 0, // TODO: contar del dia
       newSubscriptions: 0, // TODO: contar del dia
       cancelledSubscriptions: 0, // TODO: contar del dia
       revenueByPlan: byPlan
     }
   }];
   ```

5. **Save Metrics to Convex** (HTTP Request): POST a Convex
   - URL: `{{ $env.CONVEX_SITE_URL }}/mutation/finance/saveFinancialMetrics`
   - Body: { "args": { ...metricas calculadas } }

6. **Save to Agent Memory** (HTTP Request): POST a Convex
   - URL: `{{ $env.CONVEX_SITE_URL }}/mutation/finance/saveMetricsToMemory`
   - Body: { "args": { "snapshot": JSON.stringify de las metricas } }

7. **Set Agent Idle** (HTTP Request): POST a Convex upsertAgentState con status "idle"

8. **Error Handler** (Error Trigger → HTTP Request): Si cualquier nodo falla, setear agentState a "error" con el mensaje de error

   ```javascript
   const metrics = $input.first().json;
   const latest = metrics[0]; // Ultimo dia
   const weekAgo = metrics.length >= 7 ? metrics[6] : null;

   const mrrTrend = weekAgo ? ((latest.mrr - weekAgo.mrr) / weekAgo.mrr * 100).toFixed(1) : 'N/A';
   const trendEmoji = mrrTrend > 0 ? '+' : '';

   const report = `REPORTE FINANCIERO SEMANAL
   Semana del ${metrics[metrics.length-1]?.date || 'N/A'} al ${latest.date}

   MRR: USD $${latest.mrr.toLocaleString()} (${trendEmoji}${mrrTrend}%)
   Suscripciones activas: ${latest.activeSubscriptions}
   ARPU: USD $${latest.arpu.toLocaleString()}
   Churn rate: ${(latest.churnRate * 100).toFixed(1)}%
   LTV: USD $${latest.ltv.toLocaleString()}

   Por plan:
   - Inicio: USD $${latest.revenueByPlan?.inicio || 0}
   ```
