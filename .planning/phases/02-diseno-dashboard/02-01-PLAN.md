**styles.css** — Design system completo basado en `.claude/skills/app-design.md`:

- Incluir TODOS los CSS custom properties del skill (Section 15 "CSS Variables Master") como variables :root
- Importar Google Fonts: Source Sans 3 (400, 600, 700)
- Definir @font-face para Sharp Grotesk (Medium, SemiBold, Bold) apuntando a archivos locales en assets/. Si los archivos no existen, el fallback a system-ui funciona
- Definir @font-face para Nasalization apuntando a archivo local
- Componentes CSS que se necesitan para los 3 mockups:
  - `.topbar` — glassmorphism sticky (72px, blur 12px, rgba(248,247,245,0.85)), con titulo de pagina a la izquierda y org-badge + date-range a la derecha
  - `.command-bar` — input centrado estilo Claude.ai, ancho max 720px, con icono terminal a la izquierda (Lucide), placeholder "Que quieres ver?", boton send a la derecha. Debe ser el elemento visual mas prominente de la pagina
  - `.command-suggestions` — dropdown que aparece debajo del command bar con queries sugeridas, hidden por defecto
  - `.card` — superficie blanca (#FFFFFF), border 1px #e5e5e5, border-radius 16px, padding 24px, hover con shadow sutil
  - `.card-kpi` — extiende .card. Numero grande Sharp Grotesk 2.25rem bold, label Source Sans 14px color #666, delta con icono flecha y color semantico (verde si positivo, rojo si negativo)
  - `.card-kpi .narrative` — texto interpretativo debajo del KPI, Source Sans 14px, color #666666, max 2 lineas, italica. Esto es lo que diferencia a Sisteco de Apollo: el CEO lee "Tus leads HOT subieron 33%" no solo el numero
  - `.badge` — pills con border-radius 9999px. Variantes: `.badge-hot` (fondo lime sutil, texto oscuro), `.badge-warm` (fondo naranja sutil), `.badge-nurture` (fondo azul sutil), `.badge-skip` (fondo gris sutil)
  - `.funnel` — contenedor flex horizontal para el funnel de conversion. Cada paso es una barra vertical cuya altura representa el % relativo al primer paso
  - `.funnel-step` — cada paso del funnel: label arriba (12px), barra coloreada con gradiente sutil, numero absoluto y % debajo (14px bold). Colores degradados del lime al gris conforme avanza el funnel
  - `.chart-bar-h` — bar chart horizontal para segmentacion por industria/tamano. Cada barra tiene label a la izquierda (nombre industria/tamano), barra coloreada proporcional, y valor a la derecha
  - `.org-badge` — pill en el topbar con icono building (Lucide) + nombre de la organizacion ("TechCorp Chile SpA"). Background sutil, border, border-radius pill
  - `.date-range` — grupo de pills (7d, 30d, 90d, Todo). La pill activa tiene fondo lime, las otras son ghost
  - `.sidebar-mini` — sidebar colapsada a la izquierda, 64px de ancho, fondo #111111, iconos Lucide blancos centrados. Items: overview (layout-dashboard), leads (users), pipeline (git-branch), reportes (bar-chart-3), settings (settings). El item activo tiene indicador lime a la izquierda. En la parte inferior: avatar del usuario con iniciales. Al fondo: wordmark "S" en Nasalization
  - `.main-content` — area principal con margin-left: 64px (sidebar), padding 32px
  - `.section-header` — titulo de seccion con icono Lucide + texto Sharp Grotesk 20px + linea decorativa
  - `.login-badge` — badge pequeno en topbar que muestra "CEO" / "VP Ventas" / "SDR" segun el rol simulado
- Responsive: @media (max-width: 1024px) sidebar se oculta, topbar ocupa 100%; @media (max-width: 768px) KPI cards en 1 columna, funnel vertical en lugar de horizontal, padding reducido
- Grid layout: usar CSS Grid para KPI cards (auto-fill, minmax(240px, 1fr), gap 16px)
- NO usar ningun framework CSS externo — todo vanilla CSS
- Incluir media query `prefers-reduced-motion: reduce` que desactiva animaciones

**interactions.js** — Interactividad basica:

- `initLucide()`: llamar lucide.createIcons() al cargar
- `initAnimations()`: GSAP entrada escalonada de cards (y:24, opacity:0, stagger:0.08, duration:0.6, ease:power3.out). Count-up animado para numeros KPI (gsap.from con textContent snap). Fade-in del funnel (opacity:0, y:16, delay:0.4)
- `initCommandBar(role)`: al hacer focus en el input, mostrar `.command-suggestions` con queries relevantes al rol. Al hacer click en una sugerencia, simular un "loading" (spinner 0.5s) y luego mostrar un bloque de contenido inline debajo del command bar (puede ser un mensaje tipo "Mostrando: leads HOT de esta semana" con datos del mock-data). Al presionar Escape, ocultar sugerencias
- `initDateRange()`: click en pills cambia clase activa, no hace nada mas
- `initSidebar()`: click en items de sidebar cambia clase activa (highlight lime)
- `DOMContentLoaded` listener que ejecuta todos los inits
- Detectar el rol actual via `document.body.dataset.role` (cada HTML define su rol)
- NO implementar funcionalidad real — solo interactividad visual
